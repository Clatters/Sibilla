# Development platform

You can use Sibilla to bring your PureData and Max8 patches to life! <br/><br/>
Here are the PureData and Gen~ templates. <br/>
Each templates has plenty of comments with more information about the module's pinout and working architecture. <br/><br/>
All the components that act as input or output are accessible with Pd's and Gen~'s `receive` / `send` or `param` objects followed by the respective name or alias, see the patch_sm json file. <br/><br/>
Please refer to [Pd2dsy](https://github.com/Clatters/pd2dsy) and [Oopsy](https://github.com/Clatters/oopsy) for any programming and troubleshooting questions.
